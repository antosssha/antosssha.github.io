01

The challenge

The central design constraint is simple: the agent should not know what a human could not know. The research focuses on perception uncertainty, reaction delay, partial visibility and behavior under imperfect information.

01No hidden enemy coordinatesTargets must first satisfy a fair-observation layer before they can influence behavior.
02No wallhack-style stateOcclusion matters. Walls and visual blockers can make a target unavailable.
03Human-like uncertaintyReaction time, incomplete visibility and imperfect target acquisition are modeled deliberately.
04Verified ≠ plannedPublic documentation separates working behavior from experiments and future milestones.
This page describes the public research layer only. Private implementation details, datasets, model internals and infrastructure are intentionally excluded.

03

Current V1 state

BOMBAS V1 is a clean rebuild. The current public state is a perception specification and validation phase, not a claim that the agent already reproduces the old prototype's movement or combat behavior.

Defined / under validation

  • Fair-information boundary: no hidden enemy coordinates or wallhack-style state
  • Map edges, obstacles and occlusion must affect what can be perceived
  • Vertical differences must be handled rather than assuming a flat world
  • Partial visibility must include uncertainty rather than pixel-perfect detection
  • Smoke, molotovs and other visual interference must degrade perception when appropriate
  • Enemy / teammate identity must come from visual interpretation, not privileged server labels
  • Pre-round and round-state behavior must respect actual game rules

Not claimed yet

  • Reliable autonomous navigation
  • Combat skill or human-like aim quality
  • Learned tactical behavior
  • Weapon, utility and economy mastery
  • Full-round autonomous decision making
  • Long full-match validation
  • Human-level CS2 performance
04

Current limitations

The rebuild deliberately narrows the scope so later behavior is not built on a flawed perception layer.

Foundation only

V1 is currently about seeing and interpreting the world correctly. Navigation and combat are downstream stages.

No inherited claims

Results from BOMBAS V0 remain historical research evidence and are not automatically counted as V1 capability.

Fair identity

Friend-or-foe recognition must be visual. Hidden server-side team labels are outside the intended perception contract.

Human uncertainty

Tiny visible fragments, height changes and visual interference must allow realistic misses and delayed recognition rather than perfect detection.

06

V1 validation plan

The new baseline starts clean. Old V0 benchmark numbers are archived and are not used as evidence that V1 already passes the same tests.

CURRENT VALIDATION STATUSV1BASELINE06 OCT 2026 · perception-first restart

The goal is to prove the perception contract one controlled scenario at a time before reconnecting movement, combat and learning.

WORLD GEOMETRYIN VALIDATION

Map boundaries, walls, obstacles and height differences must alter the agent's visible world correctly.

PARTIAL VISIBILITYIN VALIDATION

Small exposed body regions should produce uncertain, human-like detection rather than perfect recognition.

VISUAL IDENTITYREQUIRED

Enemy and teammate classification must be derived visually rather than supplied as hidden game state.

FULL GAMEPLAYNOT CLAIMED

Autonomous rounds and match-level performance return only after the perception foundation is validated.

07

Public research principles

The public case documents what the project is trying to prove without exposing private code, datasets, exact algorithms, model internals or infrastructure.

VERSION BOUNDARY

V0 is archive, V1 is current

Historical experiments can inform design decisions, but their benchmark results do not automatically transfer into the new agent.

RuleNo inherited capability claims
FAIR INFORMATION

Perception before action

A target should influence behavior only after it passes the same public information boundary the project intends a human player to have.

RuleNo hidden enemy state
VALIDATION DISCIPLINE

Test narrow, then scale

Each perception failure mode is isolated in controlled scenarios before downstream systems are allowed to depend on it.
