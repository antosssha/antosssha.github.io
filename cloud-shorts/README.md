# GTA6 Cloud Shorts (изолированный прототип)

**Статус:** облачный рендер протестирован; коммерческое производство и автоматическая публикация **ещё не подключены**.

## Где работает

- GitHub-hosted runner Ubuntu, **не пользовательский ПК**.
- Только ветка `gta6-cloud-shorts` портфолио-репозитория; `main` не изменён.
- Запуск теста: [GitHub Actions](https://github.com/antosssha/antosssha.github.io/actions/workflows/gta6-cloud-shorts.yml).
- Результат теста: Actions Artifact `gta6-cloud-shorts-demo`, хранится 7 дней; тестовое видео синтетическое.
- Никаких браузеров, мыши, локальных Windows-служб, фонового рендера на компьютере и публикаций в YouTube.

## Что делает `render.py`

1. Требует видеовход, JSON параметров и отдельный текст подтверждения прав.
2. Рендерит видео 1080×1920 (вертикальное, с крупным видео и необязательной камерой реакции).
3. **Сохраняет оригинальный звук источника**. Синтетический голос, музыка и автосубтитры не создаются.
4. Короткие надписи (хук) без больших плашек; метка A-LAB.
5. Готовит `youtube.json` с названием и релевантными хэштегами `#GTA6 #Shorts`, при необходимости тегом стримера.
6. В описании только момент, призыв подписаться, призыв поддержать и донат-ссылка `https://www.donationalerts.com/r/younggod21`.
7. Готовит **закрытый** результат для проверки. Сам не публикует.

## Формат метаданных

Пример `clip.meta.json` (входной файл; настоящие авторизованные исходники сюда не коммитить):

```json
{
  "streamer": "ExampleStreamer",
  "streamer_hashtag": "ExampleStreamer",
  "title": "Сложная посадка в GTA VI!",
  "description": "Стример едва не потерял самолёт во время посадки.",
  "duration_sec": 23,
  "start_sec": 0,
  "hook": ["ПОСАДКА НА ГРАНИ!"],
  "crop_x": 280,
  "face": [0, 113, 270, 185]
}
```

Поле `face` опционально. Координаты лица зависят от разрешения исходника — неверные значения дадут ошибку, это ожидаемая защита. Если камеры нет, поле пропускается.

## Архитектура для реальных роликов

**Отбор клипов → разрешения авторов → приватное хранилище → GitHub Actions → приватный файл результата → проверка → YouTube API**.

Нужны следующие интеграции:

1. **Отдельный закрытый GitHub-репозиторий**, чтобы workflow и видео не перемешивались с портфолио. Подключённый GitHub-инструмент сейчас не умеет создавать репозитории; ветка — временный тестовый стенд.
2. **Закрытое хранилище** для исходников и результатов. Cloudflare R2 пока не активирован: API возвращает `403 / 10042: Please enable R2 through the Cloudflare Dashboard`. Включение требует активации тарифа в Dashboard; до активации расходов и хранения реальных видео нет.
3. **GitHub Secrets** с минимальными правами доступа к хранилищу. Никогда не коммитить токены/пароли/ссылки, дающие доступ к закрытым видео.
4. **YouTube OAuth**, авторизация владельца канала и проверка ограничений YouTube Data API. Автопубликация по умолчанию выключена: сначала `private`, затем ручное разрешение публикации. Не копировать cookies браузера и не обходить интерфейс.
5. Права на конкретные исходники: пользователь сообщил о разрешении на один момент CaseOh, но подтверждение в файле/сообщении ещё не приложено. Не считать это универсальным разрешением на клипы других стримеров.

### Конфиденциальность и бесплатные лимиты

Тестовый артефакт из **публичного** репозитория доступен в GitHub Actions. Поэтому в публичный репозиторий **никогда не загружать реальные чужие клипы, разрешения с личными данными и токены**. Для коммерческой работы требуется отдельная защищённая инфраструктура.

GitHub-hosted минуты для публичных репозиториев GitHub Actions обычно бесплатны для стандартных runners, но обработка в приватном проекте может расходовать квоту. Cloudflare R2 имеет бесплатную месячную квоту после активации, но не является «навсегда безусловно бесплатным» хранилищем: возможна плата при превышении лимитов.

## Техническая проверка

В `.github/workflows/gta6-cloud-shorts.yml` генерируется собственный короткий тестовый видеофайл, `render.py` экспортирует MP4, `verify.py` сверяет размер кадра, звук, отсутствие субтитров, обязательные поля SEO и закрытый статус. При ошибке пайплайн останавливается.

**Не распространять/публиковать файлы без проверенных прав.**
