A-LAB Shorts.
Контент без рутины.

Внутренний инструмент для создания вертикальных роликов из видеоклипов, на использование которых получено разрешение, и подготовки их к размещению на собственном YouTube-канале.

01 / Назначение приложения

Меньше ручной работы.
Больше контроля.

A-LAB Shorts помогает владельцу канала формировать короткие вертикальные видео, сохранять оригинальный звук автора, готовить название и описание и — после отдельного разрешения владельца — загружать результат через YouTube Data API в закрытом доступе.

Это личный инструмент производства контента. Публичной регистрации, автоматической загрузки чужих видео без разрешения, сбора подписчиков или просмотра личных видео других пользователей в приложении нет.

Статус · Частное использование

Монтаж в GitHub Actions протестирован. Google OAuth и автоматическая загрузка на YouTube находятся на этапе подключения. Само наличие сайта не означает, что канал уже подключён.

02 / Workflow

От разрешённого клипа — к черновику.

01 / Исходник

Проверка прав

Владелец канала выбирает клип и подтверждает право на его монтаж и самостоятельную загрузку. Система не заменяет разрешение правообладателя.

02 / Обработка

Монтаж в облаке

GitHub Actions создаёт вертикальный MP4. Звук берётся из оригинального видео; ИИ-озвучка и автоматические субтитры не добавляются.

03 / YouTube

Закрытая загрузка

После подключения Google OAuth и явного согласия владельца результат можно загрузить на выбранный YouTube-канал только со статусом Private.

03 / Google OAuth

Для чего требуется доступ к Google.

Разрешения ограничены функциями YouTube, необходимыми для проверки канала и загрузки видео. Приложение не запрашивает доступ к Gmail, Google Drive, контактам, истории поиска и паролям.

youtube.readonly

Используется для получения идентификатора и названия авторизованного YouTube-канала, чтобы не загрузить видео на другой канал по ошибке.

youtube.upload

Используется только для загрузки подготовленного MP4 с названием и описанием на выбранный YouTube-канал после подтверждения владельца. Загрузка выполняется со статусом Private.

04 / Условия использования · Terms of Service

Прозрачные правила работы.

Редакция: 19 ноября 2026 г.

Назначение и доступ

A-LAB Shorts разработан и поддерживается A-LAB как внутренний инструмент для владельца собственного YouTube-канала. Приложение предоставляется в текущем состоянии, без публичного доступа для сторонних пользователей и без гарантий непрерывной работы.

Права на видео

Пользователь обязан иметь необходимые права или разрешения на исходные видеоклипы, музыку, изображения и другие материалы. Подтверждение в интерфейсе не является автоматической юридической проверкой. Владелец канала несёт ответственность за публикуемый контент и соблюдение правил Twitch, YouTube и правообладателей.

Управление каналом

Приложение использует OAuth-разрешения только после явного согласия владельца канала. Любая загрузка через предусмотренный облачный процесс должна выполняться со статусом Private; публичная публикация остаётся отдельным решением владельца канала. Доступ можно отозвать в настройках безопасности Google.

Данные и удаление
